# 8. Quick Revision and Viva Questions

## One-line answers
- Virtualization: making virtual versions of hardware or resources.
- Hypervisor: software that creates and runs VMs.
- Type 1: runs on hardware. Type 2: runs on an OS.
- Container: light, shares host kernel.
- Docker: builds and runs containers.
- Kubernetes: manages many containers.
- IaaS / PaaS / SaaS: rent VMs / rent platform / use software.
