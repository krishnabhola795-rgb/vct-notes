# 3. Types of Virtualization

1. **Server virtualization**: one physical server runs many virtual servers.
2. **Desktop virtualization (VDI)**: your desktop runs on a remote server, and you see it on any device.
3. **Storage virtualization**: many storage devices look like one big disk (example: SAN, RAID pools).
4. **Network virtualization**: virtual switches, routers, and VLANs on shared network hardware (example: SDN).
5. **Application virtualization**: app runs without full install on your device (example: Citrix apps).
6. **OS-level virtualization**: many isolated user spaces share one OS kernel (this is **containers**, like Docker).
7. **Data virtualization**: see data from many sources in one place without moving it.

## Quick memory trick
Server, Desktop, Storage, Network, Application, OS, Data = **S D S N A O D**.
